# IA na Prática Studio Web v1

Versão web gratuita para hospedar no GitHub Pages.

## Publicar
1. Crie um repositório no GitHub (ex.: `ia-studio`).
2. Envie `index.html`, `style.css` e `app.js` para a raiz.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Branch: `main`, pasta `/ (root)` e clique **Save**.

## O que já funciona
- editor de roteiro;
- divisão automática em cenas;
- prévia 16:9 e 9:16;
- imagens locais por cena;
- teste de voz pt-BR disponível no navegador;
- salvamento do projeto em JSON;
- funciona sem servidor e sem enviar o roteiro para o site.

## Importante
Esta v1 NÃO exporta MP4. GitHub Pages é hospedagem estática e não executa FFmpeg/Piper no servidor.
A exportação profissional será uma etapa separada, para não prometer uma função que o Pages sozinho não oferece.
